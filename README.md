# 📝 Tasks API — FastAPI + MongoDB + Docker

CRUD de **Tarefas** construído com FastAPI, pymongo e Docker, com base em Arquitetura Modular:

---

## 🚀 Como executar

- Faça o git clone do repositório
- Inicie o Docker com o comando:
```bash
docker-compose up --build
```
- Acesse o projeto pelo link: http://localhost:8000/
